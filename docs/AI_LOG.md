# AI Usage Log

## 1. Purpose

This document records the use of Artificial Intelligence (AI) tools during the planning, development, documentation, and testing of the Customer Loyalty Rewards System.

## 2. AI Tool Used

- **Tool:** ChatGPT
- **Provider:** OpenAI
- **Purpose:** Learning support, project planning, development guidance, debugging assistance, and documentation support.

## 3. Areas Where AI Assistance Was Used

| Area | AI Assistance |
|---|---|
| Project Planning | Discussing project scope, requirements, modules, and business rules. |
| Database Design | Guidance on database tables, relationships, constraints, and data handling. |
| Backend Development | Explanations and assistance with Core PHP, PDO, validation, authentication, and application logic. |
| Frontend Development | Guidance on HTML, CSS, JavaScript, Bootstrap, and user interface improvements. |
| Security | Explanations and guidance on password hashing, sessions, CSRF protection, prepared statements, and access control. |
| Debugging | Helping understand errors and suggesting possible solutions during development. |
| Testing | Preparing test scenarios and explaining expected application behaviour. |
| Documentation | Assistance preparing project documentation, including assumptions, setup instructions, architecture, and test plans. |

## 4. How AI Assistance Was Used

1. Requirements and implementation decisions were discussed before development.
2. AI explanations were used to understand technical concepts and implementation approaches.
3. Development suggestions were reviewed and applied as appropriate.
4. Errors were discussed with AI to understand possible causes and solutions.
5. Application functionality was tested by the developer in the local environment.
6. Documentation was prepared with AI assistance and reviewed by the developer.

## 5. Developer Responsibility

- The developer is responsible for understanding the application's functionality and code.
- AI-generated suggestions are not treated as automatically correct.
- Code and suggestions are reviewed before being used.
- Actual application testing and verification are performed by the developer.
- Final project decisions and submitted work remain the developer's responsibility.

## 6. Transparency Note

This log summarizes the categories of AI assistance used during the project. It is not a complete transcript of every AI conversation or prompt. Exact dates, prompts, and individual contributions should only be added when they can be verified from the original records.
